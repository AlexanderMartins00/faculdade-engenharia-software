# EduSmart — Aula 13

## Tema
Integrações, Adapter e Facade

## Situação do projeto
O EduSmart contém decisões e artefatos legados possivelmente incompletos ou inadequados ao conteúdo desta aula. O aluno deve analisar o estado atual antes de modificar.

## O que o aluno deve fazer
1. definir contratos com o sistema acadêmico e serviços de notificação;
2. analisar `AcademicSystemAdapter`, `NotificationAdapter` e `EduSmartFacade`;
3. corrigir Adapter e Facade quando tecnicamente pertinente;
4. produzir código, UML/Mermaid e ADR;
5. propor topologia de implantação.

## Dicas
- Adapter deve isolar formatos externos.
- Facade não deve expor os subsistemas que deveria simplificar.

## Evidências mínimas
- Issue `Aula 13`;
- branch sugerida `aula-13`;
- commits explicativos;
- README/Markdown com problema observado, alteração realizada e critério de aceitação;
- evidência de compilação/teste quando houver código;
- PR ou revisão equivalente quando aplicável.

## Prazo operacional
O trabalho deve começar em sala e ser concluído até o início da aula seguinte, salvo orientação diferente do professor.
