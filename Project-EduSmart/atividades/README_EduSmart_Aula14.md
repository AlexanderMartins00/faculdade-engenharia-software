# EduSmart — Aula 14

## Tema
Strategy, Factory Method, Abstract Factory e Observer

## Situação do projeto
O EduSmart contém decisões e artefatos legados possivelmente incompletos ou inadequados ao conteúdo desta aula. O aluno deve analisar o estado atual antes de modificar.

## O que o aluno deve fazer
1. avaliar criticamente as implementações legadas dos quatro padrões;
2. aplicar Strategy a uma variação real, como política de média/aprovação, quando pertinente;
3. avaliar criação de diferentes tipos de avaliação para Factory Method;
4. modelar famílias coerentes de integrações quando houver justificativa para Abstract Factory;
5. permitir múltiplos interessados em eventos acadêmicos por Observer;
6. revisar os seis padrões com código, UML/Mermaid e ADR.

## Dicas
- Não force padrões.
- A regra de média precisa refletir requisitos antes da implementação.

## Evidências mínimas
- Issue `Aula 14`;
- branch sugerida `aula-14`;
- commits explicativos;
- README/Markdown com problema observado, alteração realizada e critério de aceitação;
- evidência de compilação/teste quando houver código;
- PR ou revisão equivalente quando aplicável.

## Prazo operacional
O trabalho deve começar em sala e ser concluído até o início da aula seguinte, salvo orientação diferente do professor.
