# Requisitos iniciais — legado

1. O sistema deve cadastrar cursos e turmas.
2. Deve permitir matricular alunos.
3. Professores devem lançar avaliações e notas.
4. O cálculo das médias deve estar correto.
5. O sistema deve comunicar resultados aos alunos.
6. Deve integrar com o sistema acadêmico.
7. Turmas devem poder ser fechadas.
8. O sistema deve ser seguro.
9. Deve suportar muitos alunos.
10. Deve ser fácil de manter.

Os requisitos foram deixados sem critérios de aceitação suficientes.
